# NezamMonitor Windows — مانیتور نظام مهندسی

> نرم‌افزار مدیریت هوشمند پرونده‌های نظام مهندسی برای ناظرین مکانیک

---

## 🎯 این برنامه چیکار می‌کنه؟

سایت نظام مهندسی کنده و هر بار استخراج اطلاعات وقت‌گیره. این نرم‌افزار اطلاعات رو یکبار استخراج می‌کنه و دیگه لازم نیست هر بار وارد سایت بشید.

## ✨ امکانات

| امکان | توضیح |
|-------|-------|
| 📋 مدیریت پرونده‌ها | مشاهده، جستجو و ویرایش تمام پرونده‌ها |
| 👷 مهندسین | لیست مهندسین هر پرونده با رشته و نقش |
| 💰 حق‌الزحمه | محاسبه و جمع‌بندی بر اساس مالک/مرحله/وضعیت |
| 📄 گزارش Word | تولید خودکار گزارش‌های مرحله اول، دوم و سوم |
| 📌 پیگیری | یادداشت‌برداری و ویرایش توضیحات |
| 💾 پشتیبان | ایجاد و بازیابی فایل‌های رمزنگاری‌شده |
| 📱 خروجی اندروید | انتقال اطلاعات به نسخه موبایل |
| 🔄 بروزرسانی | استخراج خودکار اطلاعات از سایت نظام |

## 🚀 نصب و اجرا

1. فایل ZIP رو دانلود کنید
2. از حالت فشرده خارج کنید (Extract)
3. NezamMonitor.App.exe رو اجرا کنید
4. در صورت نمایش هشدار Windows: روی فایل راست کلیک → Properties → Unblock

## 📋 نیازمندی‌ها

- **سیستم‌عامل:** Windows 10 یا 11 (64-bit)
- **Runtime:** .NET 8.0 Desktop Runtime ([دانلود](https://dotnet.microsoft.com/download/dotnet/8.0))
- **حداقل RAM:** 4 گیگابایت

## 🔗 ارتباط با نسخه اندروید

```
ویندوز → خروجی → .nzmdata → اندروید → وارد کردن
اندروید → ویرایش → خروجی → .nzmdata → ویندوز → وارد کردن
```

**نسخه اندروید:** [GitHub](https://github.com/Barkhordari-dev/nezammonitor-android/releases)

## ⚠️ نکات مهم

- از پوشه `data/` به‌صورت منظم پشتیبان‌گیری کنید
- پوشه `templates/` حاوی فایل‌های Word هست — حذف نکنید
- اطلاعات لاگین نظام مهندسی در خود برنامه ذخیره می‌شود
