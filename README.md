# NezamMonitor Windows

**مانیتور نظام مهندسی** — نرم‌افزار مدیریت و پیگیری پرونده‌های نظام مهندسی

## ویژگی‌ها

- 📋 **مدیریت پرونده‌ها**: مشاهده و ویرایش اطلاعات پرونده‌ها، مالکین، مهندسین
- 👷 **مهندسان**: مشاهده لیست مهندسین هر پرونده با رشته و نقش
- 💰 **حق‌الزحمه**: محاسبه و نمایش حق‌الزحمه با فیلتر و جستجو
- 📄 **گزارش‌ها**: مدیریت و تولید گزارش‌های مرحله‌ای
- 📌 **پیگیری**: یادداشت و ویرایش توضیحات پیگیری
- 💾 **پشتیبان‌گیری**: ایجاد و بازیابی فایل‌های پشتیبان رمزنگاری‌شده
- 📱 **خروجی اندروید**: انتقال اطلاعات به برنامه اندروید
- 🔄 **بروزرسانی خودکار**: استخراج اطلاعات از سایت نظام مهندسی

## نصب

1. فایل‌ها را از پوشه `release/` کپی کنید
2. فایل `NezamMonitor.App.exe` را اجرا کنید
3. در اولین اجرا، پوشه `data/` به صورت خودکار ایجاد می‌شود

## ساختار پوشه

```
NezamMonitor/
├── NezamMonitor.App.exe      ← فایل اجرایی
├── NezamMonitor.App.dll      ← کتابخانه برنامه
├── NezamMonitor.Core.dll     ← کتابخانه مرکزی
├── app_logo.png              ← آیکون برنامه
├── templates/                ← Word Templates
│   ├── مکانیک مرحله اول.docx
│   ├── مکانیک مرحله دوم.docx
│   └── مکانیک مرحله سوم.docx
└── data/                     ← دیتابیس (خودکار ایجاد می‌شود)
```

## نکات مهم

⚠️ **فایل `data/` حاوی اطلاعات حساس است** — هرگز آن را به اشتراک نگذارید

⚠️ **فایل `templates/` حاوی Word Templates است** — از آن پشتیبان‌گیری کنید

⚠️ **برای انتقال اطلاعات به اندروید** از منوی «خروجی اندروید» استفاده کنید

## توسعه

برای توسعه این برنامه:

1. `dotnet build` را در پوشه `src/` اجرا کنید
2. تغییرات را اعمال کنید
3. `dotnet publish` برای ایجاد نسخه نهایی
